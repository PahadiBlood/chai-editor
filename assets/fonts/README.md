# Export fonts

Unmodified hinted TrueType fonts from
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf (archived upstream).
`OFL.txt` retains the upstream SIL Open Font License notices.

Noto Sans regular/bold/italic/bold-italic, Noto Serif and Noto Sans Mono supply PDF
body, headings and code. Noto Sans Symbols 2 and the Devanagari, Bengali, Tamil,
Telugu, Gujarati, Gurmukhi, Kannada, Malayalam and Oriya families supply Unicode
fallbacks. Font coverage does not itself prove perfect complex-script shaping;
verify your language sample in a PDF viewer.

DOCX uses portable Arial, Georgia and Courier New style names. DOCX images use
file-name placeholders, as permitted for this first exporter.
